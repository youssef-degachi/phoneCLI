# What is Still Missing (Roadmap)

While Rove is fully functional, there are several features that could be added to reach "Production Grade" maturity:

### 🛠 Tools Enhancement
-   **Live File Editing**: Add a web-based code editor (like Monaco) to edit files directly from your phone.
-   **File Upload/Download**: Enable moving files between your mobile device and the PC.
-   **Port Forwarding GUI**: A simple toggle to expose specific local ports (e.g., 3001, 8080) via the UI.

### 🛡 Security & Management
-   **Multi-user Support**: Allowing different PINs or actual user accounts with varying permissions.
-   **Named Tunnels**: Automation for setting up permanent Cloudflare tunnel names (e.g., `my-pc.yourdomain.com`).
-   **Logs Viewer**: A dedicated page to stream and search through backend logs in real-time.

### 🎨 UI/UX Polish
-   **Customizable Dashboard**: Drag-and-drop widgets for different system stats or project controls.
-   **Native Apps**: Wrapping the PWA in Capacitor or React Native for better integration with iOS/Android features (like push notifications for server crashes).
-   **Dark/Light Mode**: Full theme customization beyond the default "OLED Black".
